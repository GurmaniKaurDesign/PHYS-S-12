Embrace

A self-sizing, breathable, smart neck brace that prioritises patient comfort without compromising immobilisation. A device that feels like an extension of the self — not an intrusion.

Comfort Compliance Care Soft Robotics Biomedical Design

The Problem

Standard emergency and post-surgical neck braces cause as much harm as they prevent. They trap heat and sweat, compress the jaw, and cause severe pressure ulcers on the chin and collarbones. Paramedics have to guess sizing under high-stress conditions — there are only a handful of standard sizes for the full range of human necks. Patients endure weeks of avoidable discomfort in a device not designed for their body, reducing compliance and increasing recovery time.

Comfort is not a luxury feature in medical equipment. It's compliance. Patients who aren't in pain wear their braces correctly.

Traditional cervical collar — one size rarely fits all

The Concept

Embrace takes a soft robotics approach — a spandex shell with sewn internal pockets housing inflatable McKibben actuators that automatically conform to the patient's neck when pressurised. A Velostat pressure sensor embedded in the fabric reads fit in real time, and a microcontroller controls the pump and solenoid valve until the correct pressure is reached independently in each zone.

Self-Sizing

McKibben pneumatic actuators — latex tubes inside braided mesh sleeves — expand radially when pressurised, distributing force evenly across the neck surface. No manual sizing. No guessing under pressure.

Breathable Shell

Pink spandex fabric chosen for both stretch and breathability — the elasticity accommodates inflation while the weave allows airflow, reducing the heat and sweat buildup that causes skin breakdown in long-term brace wear.

Smart Feedback

FSR pressure sensing detects under-tightening and over-tightening. The system inflates until target pressure is reached, then holds — no continuous monitoring needed from caregiver.

Design Intent

Research into current brace pressure points and FDA regulations informed every design decision. The goal: a device that is not only functional but humane — one that a patient would actually choose to wear.

System Architecture

Input

Velostat FSR

Handmade pressure sensor embedded in spandex fabric — reads contact force at neck interface continuously

Controller

XIAO ESP32-C3

Maps pressure to fit zones — too loose, good fit, too tight — controls pump and valve independently

Output A

Mini Air Pump

Pressurises the system — detachable once the brace reaches target fit

Output B

Solenoid Valve

Distributes air to McKibben actuator pockets — controls inflation per zone

Actuator

McKibben Muscles

Handmade from latex tubing + braided mesh — expand radially under pressure to conform to neck

Structure

Spandex Shell

Pink spandex sewn with internal pockets and sleeves — houses actuators and FSR in a wearable form

MVP — Proof of Concept

The MVP demonstrates the core Embrace concept as a wearable prototype: a sewn spandex brace with embedded pressure sensing and pneumatic self-sizing. This is a proof of concept for both form and function — the first time all the components came together in a single wearable object.

02

The Circuit — Pump + Solenoid + MOSFET

XIAO ESP32-C3 controls a mini air pump and solenoid valve via N-channel MOSFETs. The pump pressurises the system; the solenoid valve distributes air into the actuator pockets. Powered by a bench power supply for the MVP — a portable 12V solution is planned for v2. The FSR reads pressure on analog pin A0 and the loop closes when target fit is detected.

Code

C++ for XIAO ESP32-C3. Uses C++ class structure, millis() for non-blocking timing — no delay() calls. Closed-loop: FSR reads pressure, pump inflates until target, solenoid holds.

// Embrace MVP — Self-Sizing Brace // Velostat FSR on A0 | Pump on D9 | Solenoid on D10 // XIAO ESP32-C3 | No delay() | C++ class structure const int FSR_PIN = A0; const int PUMP_PIN = D9; const int SOL_PIN = D10; // Tune by watching Serial Monitor while wearing brace const int TOO_LOOSE = 150; const int GOOD_FIT = 450; const int TOO_TIGHT = 700; unsigned long lastPrint = 0; const int PRINT_MS = 100; class BraceController { private: int fsrPin, pumpPin, solPin; int looseThr, fitThr, tightThr; public: BraceController(int fsr, int pump, int sol, int loose, int fit, int tight) : fsrPin(fsr), pumpPin(pump), solPin(sol), looseThr(loose), fitThr(fit), tightThr(tight) {} void begin() { pinMode(pumpPin, OUTPUT); pinMode(solPin, OUTPUT); digitalWrite(pumpPin, LOW); digitalWrite(solPin, LOW); } int readPressure() { int raw = analogRead(fsrPin); // ESP32 12-bit ADC return map(raw, 0, 4095, 0, 1000); } void update() { int p = readPressure(); if (p < looseThr) { // Not worn — inflate digitalWrite(pumpPin, HIGH); digitalWrite(solPin, LOW); } else if (p < fitThr) { // Too loose — keep inflating digitalWrite(pumpPin, HIGH); digitalWrite(solPin, LOW); } else if (p <= tightThr) { // Good fit — hold pressure digitalWrite(pumpPin, LOW); digitalWrite(solPin, LOW); } else { // Too tight — vent digitalWrite(pumpPin, LOW); digitalWrite(solPin, HIGH); } if (millis() - lastPrint > PRINT_MS) { Serial.print("Pressure: "); Serial.print(p); Serial.print(" | "); if (p < looseThr) Serial.println("NOT WORN — inflating"); else if (p < fitThr) Serial.println("TOO LOOSE — inflating"); else if (p <= tightThr) Serial.println("✓ GOOD FIT — holding"); else Serial.println("⚠ TOO TIGHT — venting"); lastPrint = millis(); } } }; BraceController brace(FSR_PIN, PUMP_PIN, SOL_PIN, TOO_LOOSE, GOOD_FIT, TOO_TIGHT); void setup() { Serial.begin(115200); brace.begin(); Serial.println("=== Embrace MVP Ready ==="); } void loop() { brace.update(); }

Next Steps: Final version

From proof of concept to device

  • Portable power — replace bench supply with a compact 12V battery pack so the brace is untethered
  • Electronics backpack — 3D print a PLA/TPU hybrid housing: rigid PLA compartments for electronics waterproofing, flexible TPU shell with laser-cut ventilation cuts for breathability
  • Multi-zone inflation — expand from one solenoid to independent zone control for front and back actuator groups
  • Commercial FSR + actuators — replace handmade components with calibrated commercial equivalents for consistent pressure readings
  • Sewing refinement — tighter pocket tolerances, reinforced seams at actuator attachment points, cleaner sleeve construction
  • Clinical feedback — connect with medical device researchers at Harvard and MIT to validate pressure targets against cervical collar standards
