Sensor 1 — Capacitive Water Level

Self-fabricated · Capacitive sensing · Team project

Team: Chloe · Claudia · Matthew · Gurmani

A capacitive sensor measures water level by detecting changes in the dielectric properties of the material between two copper plate electrodes. As water level rises, the capacitance between the plates increases — detectable as a change in the time it takes to charge a capacitor through the sensor.

01

Building the Sensor

With 15 minutes to build a proof of concept, the team taped two copper tape electrodes on opposite sides of Claudia's water bottle — a capacitor with water as the dielectric. Alligator clips connected the copper plates to the microcontroller.

Copper tape electrodes taped to either side of the bottle

02

Controlled Environment

Initial readings were heavily influenced by hand proximity and external variables. To create a controlled environment, the team shaped a beaker from a Chloe's Clover café coffee cup, poured water in by percentage increments, and recorded readings at each level.

DIY beaker — coffee cup repurposed for controlled fill measurements

03

Circuit

Capacitive sensor circuit — Seeed Studio XIAO ESP32-C3

Code

// Week 6 — Capacitive Water Level Sensor // tx_rx method | Send: Pin 4 | Receive: A0 // No delay() — uses millis() and C++ class structure const int TX_PIN = 4; const int RX_PIN = A0; const int LED_PIN = 8; const int CAP_EMPTY = 250; const int CAP_FULL = 263; unsigned long lastPrint = 0; const int PRINT_MS = 200; class CapacitiveSensor { private: int txPin, rxPin, ledPin; public: CapacitiveSensor(int tx, int rx, int led) : txPin(tx), rxPin(rx), ledPin(led) {} void begin() { pinMode(txPin, OUTPUT); pinMode(ledPin, OUTPUT); } long read() { long total = 0; int samples = 30; for (int i = 0; i < samples; i++) { pinMode(rxPin, OUTPUT); digitalWrite(rxPin, LOW); digitalWrite(txPin, LOW); delayMicroseconds(10); pinMode(rxPin, INPUT); digitalWrite(txPin, HIGH); delayMicroseconds(10); total += digitalRead(rxPin); digitalWrite(txPin, LOW); } return total; } int waterPercent(long raw) { return constrain(map(raw, CAP_EMPTY, CAP_FULL, 0, 100), 0, 100); } void updateLED(int pct) { digitalWrite(ledPin, pct > 50 ? HIGH : LOW); } String level(int pct) { if (pct < 10) return "Empty"; if (pct < 35) return "Low"; if (pct < 65) return "Half"; if (pct < 90) return "High"; return "Full"; } }; CapacitiveSensor cap(TX_PIN, RX_PIN, LED_PIN); void setup() { Serial.begin(9600); cap.begin(); Serial.println("=== Capacitive Water Level ==="); } void loop() { long raw = cap.read(); int pct = cap.waterPercent(raw); cap.updateLED(pct); if (millis() - lastPrint > PRINT_MS) { Serial.print("Raw: "); Serial.print(raw); Serial.print(" | %: "); Serial.print(pct); Serial.print(" | "); Serial.print(cap.level(pct)); Serial.print(" | LED: "); Serial.println(pct > 50 ? "ON" : "OFF"); lastPrint = millis(); } }

Sensor 2: Hall Effect

Commercial sensor · Magnetic field detection · LED output

A Hall effect sensor detects magnetic fields by measuring the voltage across a conductor placed in a magnetic field — the Hall voltage. The analog SS49E outputs a resting voltage of ~2.5V (raw ~512) with no field present, shifting proportionally as a magnet approaches. Here it is used to detect proximity, with an LED that activates when the field is strong enough.

Basic Reading

First, I confirmed the sensor was responding correctly by reading the analog output on the Arduino Serial Monitor. The sensor produced a resting value near 336 raw (1.5V), shifting up or down as a fridge magnet approached it.

Serial Monitor resting at 336, shifted with magnet proximity

// Hall Sensor — Basic Reading const int HALL_PIN = A0; void setup() { Serial.begin(9600); } void loop() { int raw = analogRead(HALL_PIN); float voltage = raw * (5.0 / 1023.0); Serial.print("Raw: "); Serial.print(raw); Serial.print(" | Voltage: "); Serial.print(voltage, 3); Serial.println(" V"); delay(200); }

Calibrated Code

// Hall Sensor: Calibrated Proximity Detection const int HALL_PIN = A0; const float BASELINE = 336.0; unsigned long lastPrint = 0; void setup() { Serial.begin(9600); Serial.println("=== Hall Sensor Calibrated =="); } void loop() { int raw = analogRead(HALL_PIN); float voltage = raw * (5.0 / 1023.0); float fieldStrength = abs(raw - BASELINE); String proximity = ""; if (fieldStrength < 20) proximity = "No magnet / far away"; else if (fieldStrength < 80) proximity = "Magnet nearby"; else if (fieldStrength < 200) proximity = "Magnet close"; else proximity = "Magnet very close"; if (millis() - lastPrint > 150) { Serial.print("Raw: "); Serial.print(raw); Serial.print(" | Field: "); Serial.print(fieldStrength); Serial.print(" | "); Serial.println(proximity); lastPrint = millis(); } }

Connection to Embrace

A Hall sensor embedded in the brace shell could detect a small magnet mounted on the McKibben actuator bladder — measuring how far the bladder has expanded indirectly, without needing a pressure sensor inside the airway. As the bladder inflates and the magnet moves closer to the shell, the Hall sensor reading increases — giving a non-invasive measure of inflation state.
